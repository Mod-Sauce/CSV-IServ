# How to Install
Windows:
Einfach die Setup exe ausführen

Linux:
repo clonen und in die directory in die geklont wurde gehen

qmake csv_converter.pro 

make 

sudo make install  # Optional, für System-Installation 


# Build From Source
Windows und Linux:
Die .pro datei in [QtCreator](https://www.qt.io/product/development-tools) öffnen und bauen

Linux: 
Standart installation folgen
